# commands brand

## Purpose

`pooriaarab/commands` is the collection point for slash commands and shortcuts used by agent CLIs.

It belongs to the AI workspace described in the root README. The `agents` repository is that workspace's hub.

## Current state

The repository contains no implemented commands. The `commands/` directory contains only `.gitkeep`.

The repository has no application, package, command schema, release process, or deployment configuration.

## Audience

The intended readers are maintainers and agents looking for shared command definitions.

Until commands exist, this repository provides only its stated purpose and canonical design context.

## Voice

Use short, direct descriptions. Name the user action and expected result.

Do not describe placeholder behavior as implemented behavior.

## Boundaries

No logo, palette, typeface, visual interface, or product domain exists in the repository.

Do not infer command syntax or runtime rules from the sibling repositories listed in the README.
